Connect Any Tool in 5 Seconds

Point your editor, terminal, or SDK to SentinelGate. No code refactoring required.

In Cursor, Cline, Continue, or any OpenAI-compatible AI editor extension, configure custom model settings:

Base URL:
http://localhost:8000/v1
Model Name (or pass "auto" for automatic cost routing):
auto
API Key:
sk-sentinelgate-local

Export standard OpenAI environment variables to redirect any CLI tool, script, or agent through SentinelGate:

export OPENAI_BASE_URL="http://localhost:8000/v1"
export OPENAI_API_KEY="sk-sentinelgate-local"

# Now run any tool (aider, llm, fabric, custom scripts)
curl $OPENAI_BASE_URL/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -d '{"model": "auto", "messages": [{"role": "user", "content": "Hello SentinelGate"}]}'

Drop-in replacement using the official Python openai library with zero modifications to response parsing:

from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8000/v1",
    api_key="sk-sentinelgate-local"
)

# Use model="auto" to intelligently route queries and cut API bills
response = client.chat.completions.create(
    model="auto",
    messages=[{"role": "user", "content": "Explain raft consensus in 2 sentences"}]
)

print(response.choices[0].message.content)

Works directly with the official npm openai package:

import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "http://localhost:8000/v1",
  apiKey: "sk-sentinelgate-local",
});

const completion = await client.chat.completions.create({
  model: "auto",
  messages: [{ role: "user", content: "Write a quicksort in TypeScript" }],
});

console.log(completion.choices[0].message.content);
